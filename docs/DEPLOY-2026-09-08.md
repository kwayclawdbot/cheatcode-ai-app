## READ THIS FIRST: THE DATABASE IS AHEAD OF THE API

The migrations landed before the API could be deployed, because this session has
Supabase credentials and no Vercel or Expo credentials. That ordering has one
visible consequence and it is not subtle:

**Community is broken for anyone on the old build until the API is deployed.**

Why, precisely: every core room now carries `mode = null` (0045 §4(c) asserts
it). The deployed API resolves a room with

```
apps/api/src/lib/social/rooms-bridge.ts   .eq('type','core').eq('mode', mode)
```

which now matches zero rows. So on the old build:

- the room list no longer resolves for a desk;
- `coreRoomForMode()` logs `social.call_room_missing` and returns null, so a
  published call is written to `community_calls` and never reaches a room.

Nothing is lost and nothing is corrupt — the call rows are all still there, and
0040 deliberately made `community_calls.mode` the authority precisely so a room
remapping could not orphan them. It is a routing outage, not data loss, and
deploying the API ends it.

**There is no clean revert.** 0045 merged `swing` into `day-trade` and renumbered
the moved messages from the surviving room's `room_seq_counters`. Renaming the
slugs back would not un-renumber them. The way out is forward: deploy.

## THE ORDER

### 1. Deploy the API — this is the one that ends the outage

```bash
cd apps/api
vercel deploy --prod --archive=tgz --yes
```

The project is `cheatcode-ai-api` → `https://cheatcode-ai-api.vercel.app`
(`docs/ENV.md` §215). Its environment variables are already set in Vercel;
`vercel env ls production` lists them. Nothing new is required by this release.

**Verify before moving on:**
```bash
curl -s https://cheatcode-ai-api.vercel.app/api/v1/health
```

### 2. Regenerate the shared DB types

`packages/shared/db.types.ts` is generated and still declares `courses`,
`course_modules`, `lessons` and `lesson_progress`, which 0046 dropped. Nothing
reads those entries, so it is not urgent — but it is wrong, and the next person
to trust that file will be misled.

```bash
npx supabase gen types typescript --project-id eqepjztjmzmpvmlqsdiz > packages/shared/db.types.ts
```

### 3. Reload the app

Expo Go loads from a dev server, so this is a pull and a restart on the machine
running it:

```bash
git pull
cd apps/mobile
npm install          # new dependency: @react-native-community/netinfo
npx expo start --clear
```

`--clear` matters: `src/ui/theme.generated.css` was regenerated and the Metro
cache will otherwise serve the old one.

### 4. Set `API_BASE` on the site, if the funnel is wanted

`apps/site` now posts early-access to its own `/api/early-access`, which forwards
to the API server-to-server. Without `API_BASE` (or `NEXT_PUBLIC_API_BASE`) the
form returns a 503 with a sentence and the email fallback — deliberately, not
silently.
